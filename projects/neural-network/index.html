What Do Neural Networks Do?

neural networks can be thought of as rule approximators
they learn these rules gradually via many examples

rule examples:

  • functions, given x, what is y
  • classification, given factors {x1, x2, x3}, is this {y1, y2, y3}
  • prediction, given the last x words, what word comes next
  • transformation ...
  • generation ...
  • scoring ...



Key-terms / Math / Philosophy

  • weight = a number (usually floating point) stored inside a model
  • bias = a weight, with a different interpretation in the neuron
  • activation = a function that makes a weight scale its contribution
  • neuron = the actual math that links a weight, inputs, and output
  • loss = a measure of how wrong a model's prediction is
  • gradient = the direction of a model's errors per weight
  • forward pass = running the model to get a single output
  • learning rate = a constant that determines how fast to update weights
  • backpropagation = calculating and applying gradients to update weights

some words you will hear

  • MLP = multilayer perceptron, exactly what we just built
  • CNN = convolutional neural network, a neural network that uses "convolutions/kernels" as inputs
  • RNN = recurrent neural network, a network that feeds back into itself, basically keeping some state between passes
  • transformer = a neural network architecture designed to handle sequence data very quickly in parallel

summary

  • neural networks are adjustable functions that we can teach through examples
  • single neurons do very basic math, a large network leverages many neurons to do potentially very complex math
  • learning is about changing weights in a way that reduces loss
  • playing with architectures and scale allows us to use neural networks to do different things
