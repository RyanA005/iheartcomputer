02

why have a personal website?

a personal website can be an awesome tool!
you can use your website to advertise yourself, be creative, host projects, whatever...

examples:

  • portfolio, resume, projects, research
  • blog, journal, thoughts, tutorials
  • photography, artwork, music, hobbies
  • experiments, games, forums
  • whatever

reasons for

  • you get to own something
  • you can show off your work
  • you will learn web development
  • you can host useful things

reasons against

  • it takes time to build
  • you need to maintain it
  • your website can be a liability
03

three principles:

01

attention to detail:

responsiveness, accessibility, performance, consistency. a simple website done well is better than a complicated website done poorly.

02

depth:

the best websites are super exporable! link to more pages, add pages and rabbit holes for projects, ideas, whatever.

03

personality

save linkedin slop for linkedin, save aura farming for instagram, etc. your personal website should be personal


04

what do you need to know?

  • html, css, javascript
  • understand the very very basics of dns / cdn / internet
  • you can get started with a single html file and let someone else host it, or you can build an entire framework and distribute from your own machines

where to host?

github pages free, super fast and easy static sites
neocities simple, fun, old-school, huge community
* proto self hosting * best for learning, lots of control, lots of responsibility, $
self hosting most control, most responsibility, learning the hardest way...

you dont need to buy or commit to anything to get started, use whats free and easy to start
